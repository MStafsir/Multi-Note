# Task 49.12a-batch1 — Fix WHERE clause gaps (ownerId without workspaceId)

## Agent: full-stack-developer

## Summary

Fixed 22 WHERE clause locations across 15 API route files where `ownerId` was used without `workspaceId` in Prisma queries. The approach used `getWorkspaceScopeFilter(userId)` from `@/lib/workspace-scope` for routes that list/query ALL nodes a user can see (personal + workspace), and added `workspaceId` alongside `ownerId` for routes operating on specific nodes with known context.

## Pattern Used
The `workspaceScopeFilter` pattern returns:
```typescript
{ OR: [{ ownerId: userId, workspaceId: null }, { workspaceId: { in: workspaceIds } }] }
```
This is spread into WHERE clauses to ensure users can access both personal and workspace nodes they belong to.
